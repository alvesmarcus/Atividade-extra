Mural de Avisos Acadêmicos

Projeto desenvolvido para a disciplina de Laboratório de Programação Full Stack. O sistema permite publicar e visualizar avisos acadêmicos, utilizando HTML, CSS e JavaScript no front-end e Python com FastAPI no back-end.
